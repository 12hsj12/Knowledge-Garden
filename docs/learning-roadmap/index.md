## 图中文字整理

### 路线主题

**从计算机基础，到 Agent，再到第一份实习**

副标题：计算机转型学习 / Agent 开发 / Agent Infra 实践路线。

图中建议先打牢计算机和后端基础，再围绕 Agent 做可展示的真实项目，最后用项目经历准备实习求职。

### 01 计算机基础

核心提醒：认真理解，不只记结论。

- **操作系统**：进程与线程、内存、并发、I/O。
- **计算机网络**：HTTP / HTTPS、TCP / IP、连接管理。
- **数据结构与算法**：理解常用结构和算法的适用场景。
- **LeetCode 刷题**：按题型练习，复盘解题思路，分析复杂度并动手写代码；图中列出 LeetCode 热题 100、面试经典 150。
- **基础面试知识**：理解基础原理，并掌握求职中常见的高频问题。

### 02 后端开发基础

核心提醒：编程语言语法之外，先把服务写出来。

- 掌握后端通用能力：接口、分层、并发、错误处理。
- 把常见组件组合成完整服务。
- 通过经典项目把 MySQL、Redis、Kafka 用起来，结合项目理解它们并打通完整链路。

图中列出的常用组件及关注点：

- **MySQL**：SQL、索引、事务、锁。
- **Redis**：缓存设计、一致性问题。
- **Kafka**：消息机制、顺序、可重试。

### 03 Agent 项目

围绕 Agent 完成一个真实作品。共同基础包括：

- LLM API。
- 工具调用。
- 上下文管理。
- Agent 执行编排。
- 效果评估。

项目方向可以先选一个深入：

#### Agent 开发

关注流程问答、工具调用、任务执行，并能说明系统完成了什么、效果如何。

#### Agent Infra

关注调度、分布、状态、重试和观测，重点体现系统可靠性与工程能力。

图中给出两种项目练手方式：

1. **开源项目二次开发**：找到项目，理解核心实现，针对问题改进，完成线上部署并验证效果，再讲清个人贡献。
2. **论文驱动实现**：选择论文，复现并理解已有实现，改进机制，完成部署和评测，用结果说明改进效果。

阶段产出是一个能清晰讲述的作品，具备可演示、可复现或有明确亮点等特点。

### 04 实习

- 先拿到第一份真实工程经历。
- **简历与项目面试**：准备项目背景、个人贡献、设计取舍和常见深入问题。
- **持续投递与面试复盘**：结合公司规模和岗位特点，优先关注真实开发、协作与指导机会。
- **进入实习后积累素材**：补齐短板、完成真实需求，继续争取更适合的发展机会。

图中还强调了几个贯穿阶段的提示：基础认真学、持续刷题；通过项目串起核心能力；交付能讲清楚的作品；边面试边完善。
